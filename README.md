## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `pages/index.tsx`. The page auto-updates as you edit the file.

The project is a fully static site (`output: "export"` in `next.config.js`). `npm run build` writes the site to the `out/` directory, which can be served with `npm run start` or deployed to any static host. API routes are not supported in this mode.
